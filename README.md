# Cafe-Mangement-System-


A simple console-based Cafe Management System built with Python. It allows a cafe owner or staff to manage menu items, take customer orders, and generate a bill. This is a beginner-friendly project that demonstrates object-oriented programming and basic user input handling.

---

## 📌 Features

- ✅ Add menu items 
- ✅ Display cafe menu
- ✅ Take customer orders
- ✅ Generate and display bill


---

## 🛠️ Technologies Used

- Python 3
- Python basics
- Object-Oriented Programming (OOP)
